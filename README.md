# Gym Website   

This is a fully responsive practice project for a gym website.
It has been built using html, tailwind css, and javascript to practice my frontend skills - especially layout, responsiveness, and clean design.

## 📄 Pages Included:

1. Home Page: Features a hero section, services preview, testimonials, about, and call-to-action.
2. Services:  Detailed info on personal training, group fitness, and strength training.
3. About: Tells the goal of the gym and introduces the trainers.
4. Gallery: Showcases a few images from the gym environment.

## ✅ Features:
- Fully responsive (mobile, tablet, and desktop friendly)
- Clean layout and structure
- Simple and modern UI
- Testimonials section on the homepage

## ⚠️ Disclaimer
This is just a practice/dummy website.
All names, content, and images used are either fictional or not related to any real-world gym or business.
